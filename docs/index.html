SP-505 EXTRAFIRMWARE

SP-505 EXTRAfirmware patcher

Turns the official BOSS SP-505 v1.02 system update into SP-505 EXTRAfirmware. Everything runs in your browser: your file isn't uploaded anywhere.

  1. Get the official update

    On the BOSS SP-505 support page, download SP-505 System Update v1.02 SmartMedia (PC or Mac) and unzip it. It contains sp505.prg and SMPINFO0.SP0.

  2. Choose the official sp505.prg

  3. Download EXTRAfirmware

    Saves a new sp505.prg. Its contents are checked against the released build first.

  4. Install it on the SP-505

    • Copy the new sp505.prg and the official SMPINFO0.SP0 to a SmartMedia card, where the BOSS instructions put them.
    • With the card inserted, hold SONG + PTN + BPM while turning the power on, and follow the display. Don't switch off while it writes.
    • Check: hold EXIT + ENTER at power-on to see the version screen.
